# PhotoStab

Единая проявка RAW-съёмки с мероприятий. Загружаете пачку RAW — получаете чистые JPEG,
в которых вся съёмка выглядит **одним целым** — будто снята при одном свете и одних настройках
камеры: жёлтые, зелёные и синие кадры приводятся к одной белой точке, люди одинаково светлые,
ровный горизонт, естественная кожа, ИИ-шумодав для высоких ISO, восстановление
пересвета, плюс автоотбор лучших кадров из серий. Никаких стилей, LUT, виньеток и ретуши.

Программа не «вытягивает» каждый кадр по отдельности, как обычный автотюн. Она смотрит на всю
съёмку сразу:

- **Свет каждого кадра — по серым поверхностям.** Цвет света измеряется по «серым пикселям»
  (Grayness Index, Qian et al., CVPR 2019): у серой поверхности локальный контраст одинаков во всех
  каналах, каким бы ни был свет. Экран проектора, окна и цветные стены не перетягивают оценку на
  себя, как у «серого мира» и «ярких нейтралей»; серые рядом с людьми весят больше — важен свет на
  людях. Если источников несколько (лампы и экран), каждый находится отдельно. ББ камеры в оценке
  не участвует: автобаланс Canon сам прыгает от кадра к кадру и намеренно оставляет тепло ламп.
- **Вся съёмка — одна задача.** Кадры, снятые друг за другом, согласуются между собой: кадр без
  серых поверхностей берёт свет соседей, серия выглядит единой, а настоящая смена света (отошли
  от окна к лампе) сохраняется. Решается точно — динамическим программированием по цепочке кадров.
  Сверху — «одно место, один свет»: кадры в пределах полутора минут при той же яркости сцены
  получают общий свет, поэтому столики под лампами не становятся то оранжевыми, то холодными
  оттого, что с другого ракурса в кадр попала дверь с дневным светом.
- **Где есть люди, свет решают люди.** Стены, экран и окна часто освещены не тем светом, что
  лица (стена у окна — дневным, человек — тёплой лампой), и свет, «правильный» для стен, делает
  людей зеленоватыми. Поэтому на кадрах с заметными лицами (крупнее зрителей в зале) свет
  подбирается так, чтобы кожа была близка к эталону всей съёмки — тону кожи у камеры на
  автобалансе (≈ 40°), с допуском, чтобы разные люди оставались разными. Кадры без лиц берут
  свет своего места, где лица есть. Лица на картинах, рисунках и плакатах свет не решают:
  детектор их тоже находит, но при свете стен такое «лицо» жёлто-зелёное, а живая кожа при любой
  ошибке света по оси «тепло ↔ холод» бывает розовой, синей или бледной, но не зелёной. Так же
  отсеивается лицо в цветном луче сцены — цвет сцены остаётся, как его задумали.
- **Один общий тон.** Каждый кадр приводится от своего источника к одной цели — под лампами и у
  окна одинаково. Сама цель подбирается по коже людей: если камера стояла на автобалансе, кожа в
  среднем по съёмке выглядит так же тепло и насыщенно, как на JPEG камеры (привычный вид, но без её
  скачков от кадра к кадру); на фиксированном ББ камеры — естественный тон кожи по модели. Кожа не
  может стать синей или фиолетовой, даже если лицо освещено не тем светом, что стены.
- **Группы — это места съёмки** (зал у окна, столики под лампами, панель у экрана, улица,
  вспышка). Свет в зале часто меняется плавно, и по цвету кадры образуют сплошную полосу, поэтому
  группы строятся по ходу съёмки: хронология режется там, где заметно поменялись свет или яркость
  сцены, а куски с одинаковым светом склеиваются (фотограф возвращается в те же места). Мелкие
  куски присоединяются к ближайшему месту. Группы нужны для ручных правок, экспозиции и
  шумодава; правка света группы сдвигает все её кадры одинаково.
- **Экспозиция — как у камеры, люди — одинаково светлые.** Основа — яркость JPEG самой камеры
  (средний JPEG из CR3 читается за миллисекунды); по ISO, выдержке и диафрагме кадры одного света
  выравниваются между собой. Затем яркость людей тёмных серий подтягивается к хорошо освещённым
  людям съёмки (на 3/4, без лиц — наполовину): тёмные уголки под лампами светлеют, но чуть темнее
  зала остаются. Нормальные кадры не затемняются.
  Светлые участки защищены, белая точка кривой — по реальному содержимому кадра.
- **Кожа.** Коррекция тона кожи работает только на лицах (маска), стены, дерево и картины не
  трогаются.
- **Базовый вид как у камеры.** Тональная кривая подобрана по JPEG Canon «Стандарт»
  (медианная разница ≈ 2 ΔE), без дополнительной стилизации.

## Запуск

Проще всего — установщик `PhotoStab-Setup-<версия>.exe` со страницы
[Releases](https://github.com/rostislav-kuparo/PhotoStab/releases). Нужны Windows 10/11 (64 бит)
и видеокарта с DirectX 12. Ставится для текущего пользователя, без прав администратора:
программа копируется в `%LOCALAPPDATA%\Programs\PhotoStab`, ярлыки появляются на рабочем столе и
в меню «Пуск», PhotoStab находится в поиске Windows. Удаляется через «Параметры → Приложения»;
правки съёмок (`photostab.json` рядом со снимками) при этом остаются. Повторный запуск
установщика обновляет программу. Установщик не подписан, поэтому Windows SmartScreen при первом
запуске может предупредить: «Подробнее» → «Выполнить в любом случае».

Из исходников (нужен [Rust](https://rustup.rs)): `make-installer.ps1` собирает программу в
`dist\PhotoStab` и установщик `dist\PhotoStab-Setup-<версия>.exe`, а `install.ps1` ставит
собранное из `dist\PhotoStab` без установщика.

```bash
powershell -ExecutionPolicy Bypass -File make-installer.ps1
```

```bash
powershell -ExecutionPolicy Bypass -File install.ps1
```

Можно и без установки: папка `dist\PhotoStab` — готовая программа, `photostab.exe` и
`DirectML.dll` (нужны оба файла, держите их рядом).

```bash
photostab.exe
```

Откроется окно программы. Чтобы сразу открыть съёмку — перетащите папку на `photostab.exe`
или запустите:

```bash
photostab.exe "E:\Съёмки\2025-03-29"
```

Если окно не может открыться (нет Microsoft Edge WebView2 Runtime — в Windows 11 он есть всегда),
интерфейс автоматически откроется в браузере. Принудительно в браузере: `photostab.exe --browser`.

### В интерфейсе

Слева снизу — пилюля из трёх разделов (клавиши `1` `2` `3`):

1. **📁 Проекты** — «Выбрать папку…» (проводник Windows), путь вручную или перетаскивание
   RAW-файлов в окно, и список **недавних проектов** с обложками. Файлы из папки остаются на
   месте; перетащенные копируются в `Изображения\PhotoStab\upload_…`. История хранится
   в `%LOCALAPPDATA%\PhotoStab`.
2. **👁 Отбор** — сюда программа переходит сама. Плитки с JPEG камеры появляются сразу, отметки —
   после анализа (~6–7 кадров в секунду; нейросети лиц — на видеокарте, дольше всего распаковка
   CR3 на процессоре). ★ — отобран, тусклый — отбракован с причиной: дубль серии, закрыты глаза,
   **размыто** (резкость меряется абсолютно, по лицу и по самому чёткому участку кадра).
   Звёздочкой можно вернуть или убрать кадр; дальше — «К обработке».
3. **🖼 Обработка** — только отобранные кадры с проявкой, слева группы освещения. Клик по кадру — просмотр со шторкой «до / после» (слева JPEG камеры). Справа:
   - **Свет кадра** — температура и оттенок этого кадра, экспозиция группы. Правка сдвигает все
     кадры группы одинаково — так съёмка остаётся единой.
   - **Тон и цвет места** — контраст, света, тени, насыщенность, резкость: для всей группы.
   - **ИИ-шумодав** группы — яркостный и цветовой шум отдельно (как в DaVinci Resolve).
     По умолчанию включается сам по «эффективному ISO» (ISO × осветление при проявке) от ~1600.
   - **Этот кадр** — дополнительная экспозиция, восстановление светов, угол горизонта,
     коррекция кожи; ★ рядом с именем — отбор.
   - У каждого ползунка кнопка **↺** — вернуть значение, которое выбрала программа
     (подсвечена, если значение изменено вручную).
   - Иконки слева снизу: **сравнение** с камерой (`B`) и **лупа 100%** (`Z` или двойной клик):
     полное разрешение, «без шумодава / с шумодавом», сдвиг мышью, колесом или Shift+стрелками.
   - Клавиши: ← → листать, `P` — отобрать, `B` — сравнение, `Z` — лупа, `Esc` — закрыть.
4. **Экспорт…** (справа сверху в «Обработке») — JPEG с EXIF камеры и профилем sRGB в папку `Edited` внутри
   папки съёмки (или в свою). Файлы называются по папке съёмки с номером по порядку съёмки:
   `CU October 2026_001.jpg`, `CU October 2026_002.jpg`… Можно выгрузить только отобранные, полный
   размер или 3000/2048 px.

Все ручные правки сохраняются в `photostab.json` рядом со снимками и восстанавливаются
при следующем открытии папки. Правки света групп привязаны к версии автосвета: после его
обновления они не применяются (были поправкой к старому авто), но хранятся в файле; экспозиция и
шумодав сохраняются.

## Автоматические коррекции

| Что | Как |
| --- | --- |
| Баланс белого | Серые пиксели (Grayness Index) → источники света кадра (моды лог-хромы, вес у людей больше, у самых ярких — меньше); кожа — мягкая подсказка и запрет на неправдоподобный тон; согласование кадров по цепочке во времени (усечённый квадрат, точное решение); общий тон съёмки — по коже всех лиц: как на JPEG камеры (если она стояла на автобалансе) или естественный по модели |
| Экспозиция | Группа: «как у камеры» с переводом по EV100, лица вне нормы подтягиваются; затем яркость людей тёмных серий — к хорошо освещённым людям съёмки (65-й процентиль; ×0.75, без лиц ×0.5, только вверх, до +1.5 EV); защита светов (не более 4% кадра в новые яркие тона, светлые кадры не осветляются) |
| Восстановление пересвета | Где обрезан не каждый канал (тёплый прожектор: красный и зелёный упёрлись, синий жив), недостающие каналы достраиваются по цвету света с края пересвеченной зоны; «плечо» кривой продлевается, чтобы восстановленное легло ниже белого. Включается само, только если есть что восстанавливать |
| ИИ-шумодав | Два этапа. **В RAW, до демозаика** — PMRID (ECCV 2020) с k-sigma-преобразованием по профилю шума камеры: профиль (дисперсия = k·сигнал + s) меряется по самим RAW при анализе и усредняется по каждому ISO съёмки, калибровочные кадры не нужны; RAW-шумодав убирает цветные пятна и половину зерна у источника (≈1 с на кадр 24 Мп). **По картинке** — NAFNet-SIDD-width32 (fp16) дочищает яркость (0.7 силы), тайлы 512 с плавным сшиванием. Ответы сети проверяются блоками 8×8: переполнение половинной точности на насыщенных цветах (зелёная сетка) отбрасывается. RAW-этап работает при экспорте и в лупе 100%, превью — только NAFNet |
| Кожа | Замер на щеках и лбу по точкам лица; если тон ушёл в пурпур/зелень или «варёную» красноту — мягкий сдвиг только в диапазоне цветов кожи, яркость не меняется |
| Горизонт | Длинные вертикали и горизонтали, учёт перспективы; поворот только если наклон объясняет линии заметно лучше, чем «камера стояла ровно», + автокроп без чёрных углов |
| Автоотбор | Серии похожих кадров подряд; оценка — открытые глаза у всех заметных лиц (Face Mesh), резкость лица по RAW, поворот головы; 1–2 лучших кадра из серии, брак (чёрные кадры) отсеивается |

## Консольные команды

Из терминала (PowerShell, cmd) программа работает и без окна:

```bash
photostab.exe process <папка> <выход>   # всё автоматически: JPEG + report.txt (с шумодавом)
photostab.exe cull <папка> <выход>      # только автоотбор: таблица и контактные листы
photostab.exe report <папка>            # решения по каждому кадру
photostab.exe compare <папка> <выход>   # картинки «JPEG камеры | PhotoStab»
photostab.exe eval <папка> <выход>      # однородность съёмки: камера vs PhotoStab (таблица, листы)
photostab.exe noise <папка>             # профиль шума сенсора по ISO (по самим RAW)
photostab.exe nrcompare <файл> <out.jpg> # шумодавы на одном кадре: 100% кропы вокруг лица
photostab.exe nrtest <файл> <out.jpg>   # шумодав: время и 100% кропы «без | с»
photostab.exe info <файл>               # сведения о RAW, доля пересвета по каналам
```

## Требования

- Windows 10/11, видеокарта с DirectX 12 (проверено на RTX 3060 Ti); CUDA не нужна.
- Камеры: байеровские RAW, которые читает [rawler](https://github.com/dnglab/dnglab)
  (CR3/C-RAW, CR2, NEF, ARW, DNG, RW2, ORF, PEF…). Базовая кривая откалибрована по Canon EOS M50 Mark II.
  Fuji X-Trans пока не поддерживается.
- Скорость (RTX 3060 Ti, i5-10400F): анализ ~0.2 с/кадр; экспорт 24 Мп ~0.3 с/кадр,
  с ИИ-шумодавом ~6 с/кадр.

## Сборка из исходников

```bash
cargo build --release
```

Результат — `target\release\photostab.exe` и `DirectML.dll` рядом: интерфейс, ONNX Runtime
и нейросети встроены в exe. Значок программы рисуется кодом (`src/icon_draw.rs`) и вшивается
в exe при сборке (`build.rs`).

## Устройство

- `src/raw.rs` — декодирование RAW (rawler), метаданные.
- `src/gpu/` — проявка на видеокарте (wgpu, WGSL): демозаик RCD, восстановление пересвета,
  цвет, кривая, геометрия Ланцоша, резкость.
- `src/denoise.rs` — ИИ-шумодав (ONNX Runtime + DirectML).
- `src/color.rs` — температура/оттенок ↔ множители камеры (DNG-матрицы A/D65), Oklab, тональная кривая.
- `src/analysis/` — лица (YuNet), точки лица (Face Mesh), серые пиксели (`gray_index.rs`),
  ББ, свет всей съёмки (`light_graph.rs`), экспозиция, кожа, горизонт, группы освещения,
  резкость, автоотбор.
- `src/eval.rs` — замер однородности съёмки (`photostab eval`).
- `src/server.rs`, `web/` — интерфейс (axum + чистый JS); `src/desktop.rs` — окно программы (WebView2).
- `src/setup.rs` — установщик (программа внутри, ставит через `install.ps1`); собирается `make-installer.ps1`.
- `src/calibrate.rs` — калибровка базовой кривой по JPEG камеры (`photostab calibrate <папка>`).

## Сторонние модели

- `models/face_detection_yunet_2023mar.onnx` — YuNet, OpenCV Zoo, лицензия MIT.
- `models/pmrid.onnx` — PMRID (Wang et al., «Practical Deep Raw Image Denoising on Mobile
  Devices», ECCV 2020), веса [megvii-research/PMRID](https://github.com/megvii-research/PMRID),
  Apache-2.0; переведено в ONNX без изменений.
- `models/face_landmarks.onnx` — Google MediaPipe Face Mesh V2 в ONNX
  ([fernandotonon/QtMeshEditor-facemesh-onnx](https://huggingface.co/fernandotonon/QtMeshEditor-facemesh-onnx)), Apache-2.0.
- `models/nafnet_sidd_w32_512_fp16.onnx` — NAFNet-SIDD-width32
  ([megvii-research/NAFNet](https://github.com/megvii-research/NAFNet)), MIT; конвертирована в ONNX fp16
  (вход 1×3×512×512, RGB 0..1).
